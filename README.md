# CarbonChain

This is a Next.js application for managing and tracking carbon credits. It provides a comprehensive dashboard for Environmental, Social, and Governance (ESG) metrics.

## About The Project

CarbonChain is a platform designed to bring transparency and efficiency to the carbon credit market. It leverages modern web technologies and AI to provide a seamless experience for tracking, verifying, and managing a carbon credit portfolio.

### Key Features

*   **ESG Dashboard**: A central hub to get an overview of your carbon credit portfolio, including total credits owned, credits retired, active projects, and fraud alerts.
*   **Carbon Credit Management**: Track and manage all carbon credits in your portfolio with a detailed ledger.
*   **AI-Powered Verification**: Utilize AI to automatically audit IoT and on-site data to detect anomalies and potential fraudulent claims.
*   **Impact Reporting**: Generate detailed proof-of-impact reports on the environmental and social benefits of your projects.
*   **IoT Device Monitoring**: Monitor and manage connected devices from various carbon offset projects.
*   **Credit Issuance**: A streamlined process for issuing new carbon credits after successful verification.

## Tech Stack

*   **Framework**: [Next.js](https://nextjs.org/)
*   **Language**: [TypeScript](https://www.typescriptlang.org/)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **UI Components**: [ShadCN UI](https://ui.shadcn.com/)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation & Running

1.  Clone the repository.
2.  Install NPM packages:
    ```sh
    npm install
    ```
3.  Run the development server:
    ```sh
    npm run dev
    ```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result. You can start editing the main page by modifying `src/app/page.tsx`.
